# Amberline Aces — artwork usage

## Clear space

Keep clear space equal to the height of the crest shield on all four sides of
the primary crest and the wordmark.

## Approved color values

| Name | Hex | Notes |
| --- | --- | --- |
| Navy | #1b3a6b | Primary background and wordmark |
| Steel | #5d7fa3 | Secondary rules and dividers |
| Ice | #e8eef5 | Page background |
| Signal | #d94f2b | Accents, do not use as a background behind text |

## Broadcast

Use `assets/wordmark.svg` for lower-third placements. Do not recolor the
wordmark or add outlines.

## Print

Request CMYK conversions from the league design office; do not convert the
RGB values in `palette/palette.json` by hand.
