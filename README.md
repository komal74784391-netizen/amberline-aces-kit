# Amberline Aces Design Kit

Official brand and design package for the Amberline Aces of the Rivergate
Roller Derby League.

## Contents

- `palette/tokens.css` — CSS custom properties for club colors and type
- `palette/palette.json` — machine-readable color definitions
- `assets/primary-crest.svg` — approved primary crest lockup
- `assets/wordmark.svg` — horizontal wordmark for broadcast lower-thirds
- `docs/usage.md` — usage rules for print, broadcast, and digital
- `package.json` — package metadata

## Release status

Version 1.4.0 is published for the 2026 season. All artwork and palette values
in this repository are final and approved for production use.

## Quick start

```css
@import "palette/tokens.css";
```

